
# ✈️ Smart Travel Companion & Vault

אפליקציית ניהול מסמכים וליווי נסיעות חכמה, מקומית (On-Device) ובלתי מתערבת. 
האפליקציה פותרת את הלחץ והבלגן בשליפת מסמכים בזמן אמת (כרטיסי טיסה, דרכונים, שוברי מלון ורכב), תוך שימוש בחיישני המכשיר ובמנוע הקשר חכם כדי להציג תמיד את המסמך הנכון ברגע הנכון.

---

## 🌟 עקרונות הליבה

1. **פרטיות מקומית תחילה (Local & Offline First):** כל הנתונים, התמונות והעיבודים (OCR וברקודים) נשמרים ומעובדים על גבי המכשיר בלבד.
2. **אפס חיכוך (Zero-Effort Ingestion):** סריקה אוטומטית שקטה של קבצים חדשים וקובצי עבר (עד שנה אחורה) על פי עוגן תאריך הטיסה, לצד חיבור אופציונלי למייל והעלאה ידנית.
3. **עוזר שקט ובלתי מתערב:** האפליקציה לא מכתיבה מסלול קשיח ולא מציקה בהתראות מיותרות; היא מגישה כלי עזר מותאמים בדיוק לרגע שבו המשתמש זקוק להם.
4. **תמיכה מובנית בריבוי נוסעים:** מעבר מהיר בטאבים ייעודיים בין כרטיסי טיסה של כל בני המשפחה מול עמדת הסריקה.

## 🏗️ ארכיטקטורת המערכת

```text
src/
├── core/
│   ├── types/                  # הגדרות מודלים וטיפוסי נתונים (TypeScript)
│   ├── constants/              # מילוני מונחים, קבועי מערכת ומילות מפתח
│   └── database/               # אחסון מקומי מוצפן (SQLite)
├── services/
│   ├── ingestion/              # סריקת קבצים מקומית, חיבור מייל והצלבת תאריכים
│   ├── processing/             # מנועי פענוח ברקודים (BCBP) ו-OCR מקומי
│   ├── sensors/                # קריאת ברומטר, מד תאוצה, GPS ומכונת מצבים
│   └── external/               # ממשקי API לסטטוס טיסות ומפות (Google Maps)
└── presentation/
    ├── state/                  # ניהול מצב גלובלי והרשאות שקופות
    ├── components/             # רכיבי UI מודולריים (כרטיס גיבור, טאבים, בועות)
    └── screens/                # מסכי האפליקציה הראשיים
